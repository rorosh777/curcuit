# 전기회로 검사기 (circuit)

전지·전구·소켓·전선으로 회로를 직접 구성하고, 세 번의 검사로 전구가 켜지지 않는 원인이 전구 하나만이 아님을 확인하는 전기회로 진단 학습 웹앱입니다. 로그인 없이 바로 시작하고, 아무것도 저장하지 않습니다.

> 상태: 구현 1단계(부품 데이터 모델과 회로 판정) 완료, 화면 조작은 아직 없음. 대상은 중학교 과학 수업입니다. 진행 상황은 `current_status.md`, 작업 규칙은 `CLAUDE.md`를 보세요.

## 주요 기능 (1단계)

- 부품 상자에서 전지 2개, 전구 2개, 소켓 1개, 전선 3개를 회로 보드로 드래그해 배치 (불량은 전지·전구·전선 각 1개이고 어느 것이 불량인지는 세션마다 무작위, 검사 전에는 구분 불가)
- 전선 끝점을 단자에 스냅 연결, 소켓 이동 시 연결 전선 자동 분리, 전구만 교체하면 소켓 연결 유지
- 회로의 연결 상태와 부품 상태를 함께 계산해 전구 점등 여부 판정 (유효 검사 정확히 3회, 구성 오류는 횟수 차감 없음)
- 세 번째 검사 뒤 제시 문장을 따라 입력해 활동 마무리
- 키보드 조작, 도움말, 태블릿 반응형 배치, 동작 줄이기 (출시 권장 P1)

회원가입·로그인, 결과 저장과 교사용 대시보드, 점수·순위, 불량 소켓, 직렬·병렬 회로와 추가 부품, 전압·전류 계산, 기기 간 이어하기는 1단계에서 하지 않습니다.

## 데이터베이스 이름 규칙

이 앱은 DB를 쓰지 않으므로 컬렉션이 없습니다. 앱 접두사 `circuit_`는 나중에 DB가 필요해질 때를 위해 예약만 해 둡니다. 그때는 모든 컬렉션 이름을 `circuit_`로 시작하게 하고, Firestore 규칙은 `circuit_` 블록만 기존 규칙에 병합하며, PRD의 저장 금지 항목(D24, NFR07, NFR08)을 먼저 고칩니다.

## 배포 방법

1. 이 저장소에 `index.html`을 올립니다.
2. GitHub 저장소의 Settings → Pages에서 배포 브랜치(보통 `main`, 폴더 `/root`)를 지정합니다.
3. 안내된 주소를 열어 데스크톱 브라우저와 태블릿에서 동작을 확인합니다.
4. 교사는 이 주소를 학생에게 공유하면 끝입니다. 계정 설정과 관리자 지정은 필요 없습니다.

## 판정 자체 검사

주소 끝에 `#selftest`를 붙여 열면(예: `https://<배포 주소>/#selftest`, 내 컴퓨터에서는 `index.html#selftest`) 회로 판정 조합 테스트가 실행되고 결과 표가 나옵니다. 맨 위에 "모두 통과"가 보이면 정상입니다. 지원 브라우저(Chrome, Edge, Safari)마다 한 번씩 열어 결과가 같은지 확인합니다.

## 보안과 개인정보 주의

- 이 앱은 학생 이름, 학급, 기기 식별자를 받지 않습니다.
- 부품 이동·연결 이력, 검사 결과, 입력한 문장, 완료 여부와 소요 시간을 서버나 브라우저 저장소(localStorage, sessionStorage, IndexedDB, 쿠키)에 저장하지 않습니다. 새로고침하면 처음부터 다시 시작합니다.
- 이 저장소에는 개인정보를 넣지 않습니다.
